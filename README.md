# GOGMotherVRPatcher

GOGMotherVRPatcher is a tool to patch MotherVR v0.8.1 to be compatible with the GOG Store version.

**Version History**
- v1.0.0: First release version.

**Installation**

First download MotherVR v0.8.1 (https://github.com/Nibre/MotherVR/releases/tag/0.8.1) and extract the zip in your GOG Alien Isolation folder.
Extract *GOGMotherVRPatcher.exe* from the zip folder to the GOG Alien Isolation folder and run it to patch MotherVR.
Afterwards use *ai.exe* to start the game as usual. If on Windows11 and you get an Application Error 0xc00000005 error, apply the *AIWin11Fix.reg* file for a fix.
